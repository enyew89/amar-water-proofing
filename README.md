# AMAR WATER PROOFING — Portfolio Website

A modern, attractive frontend portfolio website for **AMAR WATER PROOFING**, built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **Hero section** with gradient overlay and animated content
- **Services showcase** — 6 waterproofing service cards with images
- **About section** with company story and 4-step process
- **Stats bar** — years, projects, clients, warranty
- **Project portfolio** with category filter
- **Client testimonials**
- **Contact form** (frontend only — no backend)
- **Fully responsive** mobile-first design
- **Smooth scroll animations** via Framer Motion

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Customization

Edit company details, services, projects, and testimonials in:

```
src/data/content.ts
```

Update phone, email, address, and all text content there.

## Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide Icons](https://lucide.dev/)
